# AI 生成操作说明

## 启动和创作

关闭正在运行的旧版工坊，双击工作区的「启动示例工坊.cmd」。新版 Windows 程序位于 `release/generation-client/win-unpacked/素材工坊.exe`，侧栏新增「AI 生成」。

1. 打开「模型与工作流连接」，保存连接并检查认证。
2. 选择生成连接和模型，填写提示词、尺寸和数量。原画、图标、UI、贴图和精灵按钮提供可修改的基础提示词。
3. 参考图可从文件选择器或当前素材库添加。支持蒙版的模型可在主参考图上绘制红色修改区域；擦除、撤销和清空均在原图坐标上操作，保存为原尺寸 RGBA PNG，透明区域表示需要修改。
4. 点击「预览生成方案」，检查总调用数量、每项模型、提示词、参考图与参数。可直接修改方案后启动。批次最多 20 次调用，工作流的一次调用可能返回多张图片。
5. 放大候选或选中 2–4 张并排比较；「继续修改」把候选保存为新参考图，保留原候选 ID。历史与风格预设可恢复已记录的参数和参考图。
6. 选中满意的候选并入库，可同时加入项目。入库后沿用原有预览、项目和 Godot／标准包导出流程。重复点击同一候选入库不会创建重复素材。

候选、参考图和蒙版保存在当前素材库的 `generations/` 目录，预览缓存清理不会删除它们。删除候选会移除生成目录中的该图片，已经入库的托管原件仍可使用。

## Codex

程序自动查找当前电脑的 Codex 可执行文件，也可手动通过选择器指定。复用已有登录，不要求 OpenAI API 密钥。可填写 Codex 模型 ID；留空使用 CLI 当前默认模型。

「Codex 制作助手」根据需求、当前模型能力与参考图编写结构化方案，不自行提交生成任务；方案条数最多为当前设置的生成数量。你检查和修改后点击「开始生成」。

直接生图通过 `codex exec --json` 使用内置图片工具，在独立工作目录运行，必须取得本次 `result.png` 并完成图片解码校验，才能成为候选。不会把“图片已生成”的文字回复当作结果，也不会自动改用其他 API。尺寸为生成指导；模型返回的真实尺寸显示在候选下方。Codex 的本机 CLI 是云端入口，当前版不提供离线推理。

## OpenAI 与兼容服务

官方服务地址填写 `https://api.openai.com/v1`；兼容服务填写其 Images API 基址和图像模型 ID。服务地址必须为 HTTPS，本机代理可使用 HTTP。密钥在 Electron 主进程中用系统 `safeStorage` 加密保存，只在请求时传给后台服务。

文生图调用 `/images/generations`，参考图与蒙版修改调用 multipart `/images/edits`。默认使用 GPT Image 的 `output_format=png` 参数与可配置质量。其他兼容服务需要支持这些 Images 参数；不是只兼容聊天接口就能生图。质量、参考图、蒙版、透明背景、种子及独立反向提示词须按实际服务能力配置；不支持的控制项不显示。

「检查连接」只查询认证和模型列表，不触发生图或推断编辑能力已验证。生成、参考图和蒙版兼容性需分别通过真实调用验证。局部修改是否严格保留所有像素取决于所选模型。

## RunningHub 工作流

默认服务地址为 `https://www.runninghub.cn`，国际站可配置为 `https://www.runninghub.ai`。填写有调用权限的 API 密钥和工作流 ID 或链接。首期使用工作流 API，不使用 AI App 接口。

先保存配置，再从平台读取工作流 API JSON，或通过文件选择器导入 API JSON。节点编辑器导出的普通界面 JSON 不能直接替代 API JSON。程序建议初始映射，你需要检查每一个字段：

| 可控输入 | 对应内容 |
|---|---|
| 提示词／反向提示词 | 文本编码节点的相应字段 |
| 参考图／蒙版 | 接收上传文件名的图片字段，多个参考按映射顺序排列 |
| 宽／高 | 工作流实际使用的尺寸字段 |
| 种子、步数、CFG | 采样器或其他控制节点字段 |
| 自定义 | 需要保留在界面中调整的其余原始参数 |

保存映射后，界面从映射中计算能力。没有主提示词映射的工作流不能提交。保留工作流默认值的方法是将对应附加参数留空。工作流中的密钥字段需要先移除，避免进入记录或素材包。

后台先上传参考图和蒙版，提交工作流后立即保存远端任务 ID，再查询结果并下载 PNG／JPEG／WebP。其他媒体输出不进入第一版候选库。

## 任务、费用和恢复

全局后台并发上限为 2，Codex 同时最多 1 个任务，包括制作助手。每项请求提交前保存快照，逐项保存完成候选。部分失败后可以重试未完成项，已完成图片不会重新调用模型。

RunningHub 已保存任务 ID 的未完成任务会在正常重启后继续查询；已保存结果 URL 的任务重试只下载结果。无法确认远端是否收到请求时，标记「需检查」，不会自动重复提交。先核对平台任务记录，再确认重试；重新提交可能再次消耗额度。

停止任务时会按服务能力撤销远端任务。RunningHub 返回取消成功才标记远端取消已确认；Codex 和同步 Images 接口主要停止本机处理，界面会说明已发出的云端请求可能继续。取消后完成的候选仍保留。

可填写每次调用的估算费用及 CNY／USD 币种；同一方案所有连接配置同币种价格时才累加估算，其他情况显示费用未知。Codex 使用当前登录额度。程序不会自动切换服务。

生成连接属于应用；历史、候选和风格预设属于当前素材库。API 密钥不进入任务记录、日志、素材包或素材库备份。完整备份恢复和清单重建保留候选、参考图、蒙版及生成记录；恢复到新库不会自动重放旧机器的任务。标准包再导入保留素材的生成来源、参数、参考图哈希和修改来源，不包含账户连接与 API 密钥。

## 已验证与待联调

2026 年 10 月 4 日，实际 Codex 登录检查、制作助手、真实 PNG 生图、文件回收和入库已通过。证据见 Codex 验收记录（本地生成文件：generation-codex-qa.json）。后台测试验证了 OpenAI 与 RunningHub 的请求、上传、蒙版、权限、限流、超时、取消和恢复；Electron 验证覆盖连接配置 → 候选生成 → 比较 → 蒙版修改 → 入库 → 项目 → 导出。

目前没有提供可用的云端 API 密钥和 RunningHub 工作流权限，OpenAI／兼容服务与 RunningHub 只完成模拟服务联调，尚未声称真实云端生成通过。请在程序连接设置中配置自己的账户；不要将密钥写入提示词或分享在聊天中。
