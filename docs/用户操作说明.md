# 素材工坊用户操作说明

本说明介绍 0.1.0 中实际可用的导入、整理、预览、材质、导出与恢复流程。所有成功导入的文件都有库内副本，完成导入后可以删除外部原文件。原件在工坊内保持不变；编辑结果以材质变体或新素材版本保存。

## 开始使用

首次直接启动时使用系统用户数据目录下的 `Library`。在「设置 → 本地素材库」可打开已有库或选择空目录建立新库。建议使用容量充足的本地 SSD。一个库同时只允许一个写入实例；切换前完成或取消运行、排队及暂停任务。

当前工作区的「启动示例工坊.cmd」会打开 `.data/library`。它已经包含原画、UI、控件提示图、像素图集、自然模型、动画角色、PBR 材质、带贴图木箱和 HDRI。两个项目共用公共库，加入项目不会再次复制文件。

## AI 生成

侧栏「AI 生成」提供 Codex、OpenAI／兼容 Images API 与 RunningHub 图片工作流，支持参考图、局部蒙版、批量候选、比较、继续修改、制作助手方案和挑选入库。候选先保存为生成历史，确认后才进入素材库。连接、计费、取消和恢复方式见 [AI 生成操作说明](AI生成操作说明.md)。

## 导入与整理

同类物件可从素材菜单或生成候选点击「制作同类素材」，固定样板后填写变化清单，逐项选定并加工为统一规格。模板名称、分类和项目直接进入整理确认，额外识图需要主动选择。详见 [同类素材制作流程](同类素材制作流程.md)。

右键素材或「更多操作」可快速整理、关联、检查依赖、复制路径和导出。批量整理集中设置标题、标签、分类及关联；空白处菜单支持跨分页全选和反选。详见 [右键菜单操作说明](右键菜单操作说明.md)。

点击「导入素材」选择文件、目录或 ZIP，也可以从系统文件管理器拖入。检查摘要中的文件数量、图片和模型数量、材质套组、解压空间、磁盘可用空间，以及本地依赖问题。选择项目、类别和标签，再开始导入。

「游戏实体」按角色与 NPC、敌人与怪物、动物与伙伴、武器与装备、拾取物与消耗品、交互物与机关、建筑与关卡模块、家具与生活道具、采集农业生产、载具与交通、自然与地貌筛选。实体分类与 2D、3D、贴图等素材分类独立；导入时根据文件名和用途识别，也可在详情或批量整理中修改。筛选栏中的「玩法用途」支持战斗、交互解谜、拾取奖励、采集、生产、运输等标签。

点击素材库右上角「智能聚合」，在「按实体智能聚合」与「按素材包聚合」之间切换。实体模式汇合同一版本中的同名格式、开关状态、已关联的贴图与动画；共享贴图不会把不同模型合并。整包模式按素材包版本汇总全部普通素材。自动识别依赖文件名及已有依赖关系，特殊命名或跨包搭配请多选后使用「整理 → 聚合组 → 将所选素材合并为一组」。恢复自动聚合时选择「移除手动组」。

点击聚合卡片名称选择整组，Ctrl 可追加选择；点击缩略图或双击卡片放大查看代表素材。「选择全部组」覆盖当前筛选的所有分页并去重。筛选只要命中组内一个成员，就显示完整组，所以关联素材数量可能大于普通浏览的匹配数量。「查看成员」可逐页核对清单、整组加入工坊项目；「整组导入」或「导入游戏工程」打开原有导出检查，选择 Godot 工程或通用资源包。「聚合交付」默认勾选，同包素材共用目录并保留相对依赖路径；不同版本分别交付。Godot 默认优先采用同一对象的 GLB/glTF，减少重复模型及其他格式的导入差异；可以取消该选项保留所有格式，检查结果会显示最终交付数量。素材包含外观资源及动画，游戏中的行为脚本仍需在目标工程配置。

导入先复制到暂存区、计算 SHA-256、解析媒体和依赖，然后提交文件与数据库。摘要对最多 500 个本地模型入口进行依赖预检查；ZIP 先检查目录和容量，完整依赖在解压后解析。损坏图片仍保存原件并显示失败原因；缩略图失败不撤销导入。

相同包按路径与内容哈希复用。相同名字的不同内容分别保存；没有把单文件重复检测当作物理文件级去重。发现缺失贴图时，将模型及依赖放在同一目录重新导入。当前版本不提供逐个补齐依赖的定位向导。

网格支持滚动加载、缩略图大小与列表视图。按 Ctrl 多选，按 Shift 选择当前加载范围。选择后可批量修改分类、追加或替换标签、加入项目、移出当前项目、加入现有或新收藏集、收藏和导出。「所有文件」显示被材质卡片或模型隐藏的依赖素材条目；详情中的包内文件列表可以检查说明、缓冲和许可证文件。

智能收藏集保存当前筛选条件。中文一两个字采用受控子串查询，三个及以上字符使用 FTS5 trigram。百分号、引号等按普通文字搜索。

## 图片和控件

点击缩略图即可放大查看，普通浏览和智能聚合均支持；也可双击卡片或选中卡片后按 Enter。点击名称选择素材，Ctrl 多选和 Shift 连选不会弹出放大窗口。聚合卡片的“查看成员”继续用于浏览整组内容。展开后使用滚轮缩放和拖动平移，切换透明棋盘、深浅或自定义背景、RGBA 通道、像素显示与网格。通道预览和非原生格式的详细预览最大边长为 4096；保留完整原件。

在「图集 / 帧序列」选择帧宽高、FPS 与播放位置；TexturePacker JSON 的常见对象和数组布局会自动关联同目录图像。保存参数后重新打开恢复。旋转图集帧当前跳过，不做反旋转还原。

「九宫格」填写上下左右边距，拖动预览右下角查看拉伸，点击「保存边距」。它保存素材浏览参数，不生成 Godot 控件布局。

选择 2–12 张图片后使用「右键 → 素材工具 → 控件状态分组…」，为每张填写 normal、hover、pressed、disabled 等名称。在组内任一图片的查看器选择「控件状态对照」即可并排查看。导出会携带组内图片和状态引用，标准包重新导入会更新发生冲突的 ID。

多页 TIFF 可以切换页面。普通 GIF 使用 Chromium 播放；图集播放使用单独的帧序列功能。

## 模型与材质

GLB/glTF 为主要模型格式。打开后根据包围盒设置相机，保持真实几何尺寸。拖动旋转、平移或缩放，切换透视和正交视图、网格、法线、纯色、线框或 UV 棋盘；节点列表支持选取、显示和聚焦。动画提供切换、暂停、速度和时间定位。

图片和模型都通过库内资源协议加载。模型中的远程链接不会自动请求。压缩 glTF 的解码文件随客户端打包。FBX 还原取决于 Three.js 支持范围；Kenney 示例的模型、动画文件和本地纹理已显式关联。FBX/OBJ 可在模型右键菜单点击「生成 GLB 副本」，先检查预览，再将副本纳入素材库。BLEND 需要在设置中选择 Blender 才能转换；源文件仍保留。

进入「材质工作台」，选择标准 PBR 材质槽，从图片选择器或拖入素材卡绑定贴图，确认每个通道及 UV，再调整参数。Base Color 和 Emission 使用颜色空间，其他通道作为数据。DirectX 法线通过法线强度符号在预览中适配，导出生成翻转绿色通道的 OpenGL 派生图。垂直翻转与法线方向分别处理。

粗糙度与金属度绑定共用导出约定；通道合并最大支持 8K，工作台实时通道预览最大 2K。缺少所选 UV、已删除纹理、无法解析的图片或复杂材质扩展会阻止保存或导出。独立 Godot 材质暂不支持 UV1 与旋转。

填写变体名称保存；原件不会被覆盖。选择已保存变体可继续编辑，在材质菜单中点击「新建变体」创建另一份。使用菜单「并排对照」查看当前编辑与原材质或另一个已保存变体。屏幕截图通过系统保存对话框输出 PNG。

## 固定版本与项目升级

详情「版本 → 导入新版本」选择编辑后的文件或完整目录。相同相对路径会关联到原版本的逻辑素材 ID，并保留编辑后的标题、类别和标签。新的库内记录拥有独立版本 ID。公共库允许同时浏览多个版本。

项目仍固定旧记录。选择旧版本，在版本列表中点击「将某项目切换到此版本」才升级，项目此前选择的材质变体会重置，便于重新确认。删除项目只移除组织关系。材质变体始终绑定具体模型与贴图版本。

## Godot 和通用导出

选择素材或项目资源，点击导出。选择含 `project.godot` 的工程目录会写入 `assets/workshop/`；选择普通目录会写入 `workshop-assets/`。选择所需材质变体，先检查依赖、UV、格式和通道，再开始导出。

未编辑 GLB/glTF 复制原资源与依赖。编辑的 GLB 拆成 glTF 和缓冲，保留节点、几何、骨骼与动画，生成独立变体资源和必要的贴图。独立 PBR 材质导出 `.tres`。Godot 自己生成导入缓存与 UID。

已有相同内容复用；不同版本进入新目录。目标文件内容发生人工变化时停止覆盖。导出算法升级或变体参数改变生成新的派生路径，已有场景仍能引用旧文件。若需要更新旧场景，应在 Godot 中明确切换资源。

通用导出携带原件、依赖、变体、来源、许可证、`workshop-manifest.json` 与 `workshop-export.json`，可打成 ZIP 后再次导入工坊。像素素材的最近邻过滤在 Godot 4 的节点或项目 Texture Filter 设置中选择；工坊不写旧版本导入配置。

## 任务与数据保护

任务中心显示下载、复制、解析、提交、导出和备份阶段。可暂停、继续、取消与重试；重启恢复未完成任务。复制检查点和 HTTP Range 减少重复工作；上游内容改变时重新下载。取消只清理本任务暂存内容。解析子进程失败或超时保留原件，下一任务重建解析进程。

「创建完整备份」选择库外目录。备份先创建 SQLite 一致性快照，再复制快照引用的原件、许可证、项目关系、变体和元数据，并校验原件哈希；缓存不包含在内。

恢复时选择备份目录和新的空目录。文件全部校验后复制，旧机器的运行或暂停任务不会自动重放，Godot 与 Blender 路径清空，需要重新绑定。验证任务完成后，在设置中打开恢复后的库。

「从清单重建到新目录」可恢复项目、标签、备注、变体与来源。数据库已经无法启动时，关闭客户端后运行：

```sh
pnpm recover "原素材库路径" "新的空目录路径"
```

重建依赖 `packages/` 中完整清单与原件；最近的 `metadata/catalog.json` 提供组织关系。它不能替代完整备份，也不能恢复已经丢失的原件。重建输出保留原库，遇到哈希不符会停止。

逻辑删除进入回收站，可恢复。永久清理只针对回收站条目；仍被项目或变体引用时会拒绝。只有某个版本的所有素材记录均已清除，才删除该版本原件目录，不会因为删除一个依赖条目而破坏其他素材。
