# 同类素材制作流程

从素材菜单或生成候选点击「制作同类素材」，也可以使用左侧「同类素材」。第一套案例是《字阵山河》的 8 件装备和 6 种兵法；流程适用于其他项目的同类透明物件图标。

## 使用步骤

1. 选择参考样板，填写固定风格与材质、视角、光照，选择生成连接和项目。默认使用已有 Codex 连接；原有风格预设仍可选择。
2. 清单填写稳定 ID、名称、主体、点缀颜色和装饰意象。每项默认两个候选，允许 1–4 个。ID 建议使用 `gear.blade`、`skill.fire` 等英文稳定键。
3. 建立批次。先在「破阵刀」点击「重做此项」，检查调用数量和费用估算后生成两个候选。点击图片可放大；逐项「选用此图」。生成过程中可以挑选已经返回的候选。
4. 在满意候选点击「设为新样板」。工坊创建新的模板版本与批次，保留已选候选和原始生成记录；原批次固定使用原版本。用「卧龙羽扇」和「火攻」检查不同主体的风格，再生成剩余条目。
5. 单项不满意时使用「重做此项」；微调使用「继续修改」，输入本次变化。原始候选保留在生成历史，修改记录携带父候选来源。
6. 点击「加工选定结果」。透明 PNG 先裁去透明空白，裁切阈值为 8/255，忽略近透明杂点对主体边界的影响；主体适配 384×384，四边透明补 64 像素成为 512×512，再派生 128×128、64×64。界面显示三种加工结果，便于检查留白和小尺寸辨识度。
7. 点击「整理并保存」，检查模板带来的名称、分类与目标项目。允许修改名称与类别，条目 ID 始终稳定。额外的「识图补充整理建议」需要主动启动；默认加工与保存不产生识图调用。
8. 保存后按「条目＋尺寸」聚合，自动使用英文 ID 命名，例如 `gear_blade_512x512_v01.png`。重复保存续接同一加工结果，不重复入库。制作新的图标版本应建立新批次。
9. 点击「交付游戏项目」。已有项目路径直接使用，否则选择 Godot 工程或交付目录。交付前检查文件数和问题，继续使用已有文件版本与覆盖保护。

## 交付与游戏读取

Godot 工程的默认交付位置为 `assets/workshop/`。同一条目的三种尺寸放在同一条目目录；普通资源包保留相同的素材信息。

额外的 `workshop-family-index.json` 记录本批次的稳定键、模板版本、实际相对路径、尺寸、格式及 SHA-256。示例结构如下；路径与 ID 以实际导出为准：

```json
{
  "schemaVersion": 1,
  "batchId": "本批次 ID",
  "items": {
    "gear.blade": {
      "name": "破阵刀",
      "templateVersion": 2,
      "sizes": {
        "512": { "path": "families/模板组/v2-批次/gear.blade/gear_blade_512x512_v01.png", "width": 512, "height": 512, "format": "png", "transparent": true },
        "128": { "path": "实际 128 图路径", "width": 128, "height": 128 },
        "64": { "path": "实际 64 图路径", "width": 64, "height": 64 }
      }
    }
  }
}
```

《字阵山河》通过 `scripts/workshop_icons.gd` 统一读取此索引。装备列表、详情标题旁和兵法卡片显示独立图标，缺失时沿用原来的头像或字兵；装备效果演示、描述、购买、携带和兵法交互继续使用原逻辑。索引代表一次批次交付；完整套装建议一起交付。

## 失败、恢复与保存关系

每批最多 20 次生成调用，超限自动拆分；真实生成任务使用原有总并发二、Codex 并发一。每项显示完成、生成中、等待和未完成数量。

「续接未完成任务」保留已完成候选和已保存加工结果。停止会停止关联任务；结果不明的云端调用在重新提交前要求检查平台记录。程序重启后可以从历史批次恢复；已经提交的生成不会静默重放。候选和加工文件被批次引用时会保留来源。

数据库备份与恢复包含模板版本、批次、候选选择、加工记录与尺寸关系。通用包往返保留素材上的模板、版本、条目与聚合信息；导入到另一素材库时，项目归属仍由目标库自行设置。

## 开发接口

- `families.templates.list/save`：固定生成参数、样板参考和本地加工配方；修改创建新版本。
- `families.batches.list/create/detail/update/select`：稳定条目、批次快照、候选选择及逐项进度。`sourceBatchId` 可复制清单及已选候选。
- `families.generate.preview/start`：编译条目提示词、拆批、核对调用数量与费用，再复用现有生成后台。
- `families.prepare.start` / `families.save.start`：统一加工并预填整理草稿，再执行已有保存与整理。
- `families.analyze.preview`：创建可选补充识图草稿，由现有 `processing.organize.start` 主动启动。
- `families.export.inspect`：准备本批次导出。普通 `exports.inspect` 也可传可选 `familyBatchId`。

第一版采用透明物件图标加工规格。武将肖像后续使用单张生成后组图集；字兵继续使用 Blender 的准确字形和透明渲染流程。
