# 皮肤系统与 Skin Protocol v1

在「设置 → 外观与皮肤」选择漫画、清爽或纸感，点击「应用」即可切换整套界面。密度与动效单独设置；系统减少动画设置优先。切换保留当前输入、选择及页面状态，不改变图片、材质、模型或缩略图的实际内容。

「导入皮肤」安装 `.awskin`、ZIP 或含 `skin.json` 的目录，安装不自动应用。皮肤独立保存于客户端用户目录，切换素材库或删除源图片不会移除已安装主题。卸载当前皮肤会切回漫画；启动时损坏的皮肤也会回退并提示。

## 从素材组装皮肤

1. 在设置里点击「素材组包」，选择基础风格，填写名称、作者和整包授权说明。
2. 添加视觉槽位，选择组件、底板／边框／状态标记／图标／装饰及状态。图标使用现有控件中的图标位置，不改变文字布局。
3. 选择库内图片，图集可选择独立区域；配置倍率、缩放、九宫格与文字安全区。
4. 在右侧真实控件中检查视觉，再点击「校验并生成皮肤包」。皮肤被安装，同时生成入库任务；到「界面皮肤」分类查看。

未绑定的控件沿用基础风格。第一版负责素材组装，不包含绘图或任意 CSS 编辑。标题、输入、业务文字和点击区域仍由真实 HTML 控件负责，图片素材请勿嵌入按钮文字。原图为 2× 时，尺寸及切片填写逻辑像素；图集区域使用原文件像素。

## 文件与接口

`.awskin` 是 ZIP：根目录 `skin.json`，源图位于 `resources/`，真实控件预览位于 `preview/`，可复用视觉位于 `exports/`。`exports/index.json` 标记控件、槽位、状态、逻辑尺寸、透明留边、切片、安全区和来源。完整控件预览含文字，视觉素材只包含底板、描边与装饰。

协议 schema 见 [skin.schema.json](skins/skin.schema.json)，32 类组件的完整占位索引见 [slots-v1.json](skins/slots-v1.json)。共享 TypeScript 类型和运行时校验来自 `src/shared/skins.ts`，不修改现有素材包清单版本。`atlasRegion` 记录来源图集名称、原像素区域和来源图片尺寸；包内存储已经裁出的独立图片，安装后无需原图集。

```json
{
  "kind": "asset-workshop-skin",
  "schemaVersion": 1,
  "id": "my-fresh-skin",
  "name": "我的清爽皮肤",
  "version": "1.0.0",
  "author": "作者",
  "license": "仅个人使用；各素材遵循原授权",
  "basePreset": "fresh",
  "tokens": { "accent": "#1265C8", "focus": "#007C85" },
  "resources": [{
    "id": "button-plate", "path": "resources/button.png",
    "width": 180, "height": 36, "scale": 1,
    "source": { "author": "原作者", "license": "CC0" }
  }],
  "bindings": [{
    "component": "primary-button", "slot": "background", "state": "default",
    "resource": "button-plate", "fit": "nine-slice", "bleed": 0,
    "slices": { "top": 6, "right": 6, "bottom": 6, "left": 6 },
    "contentInsets": { "top": 4, "right": 12, "bottom": 4, "left": 12 }
  }]
}
```

配色变量是 `canvas / surface / raised / text / muted / border / accent / cyan / violet / onAccent / success / warning / error / focus / shadow`，值仅接受六位十六进制颜色。`basePreset` 为 `comic / fresh / paper`。旧组件的 `red / cyan / violet` 配色接口继续映射到皮肤的三个强调色。

缩放方式为 `nine-slice / stretch / contain / tile`。切片及安全区不能超过源图尺寸；安全区记录给素材使用者，客户端保持注册表中的文字及交互布局。装饰溢出最多 8px，标记绘制在控件角落，所有装饰忽略鼠标事件。单个组件／槽位／状态只能绑定一次；资源 ID、路径必须唯一。

缺少可选状态使用基础风格或默认底板。禁用与加载继续由真实控件控制；资源覆盖不能恢复禁用按钮的操作。v1 不接受脚本、外部资源或任意 CSS，SVG 必须自包含且只使用图形，原件保留，应用时使用 PNG 缓存。安装前检查全部资源及尺寸，包容量上限 256 MiB／4096 文件，单张资源最大 8192×8192 像素及 32 MiB。

`Theme` 增加可选 `skin: SkinDefinition`，原 `accent / density / motion` 接口不变。嵌套预览独立作用域，菜单及原生弹窗继承上下文。IPC 包括 `skins.protocol/list/get/inspect/preview/create/install/remove/saveAsset/export`、`appearance.get/update`；外观独立写入 `appearance.json`，库设置保持原接口。

## 导出与开发验证

主题卡片「导出」生成完整 `.awskin`；「预览 → 导出拆分素材」生成 ZIP。素材详情也提供安装应用及两种导出。源 SVG 保留，PNG 提供 1× 和 2×，图集绑定导出为独立图片。底板含完整描边和阴影，四周各留 24 个逻辑像素；索引中的 `width/height` 是控件尺寸，`fileWidth/fileHeight` 是包含留边的 PNG 尺寸。`slices` 与 `contentInsets` 已加上留边，`sourceSlices` 与 `controlContentInsets` 保留原始数值。生成视觉使用现有组件视觉类与槽位规则，在隐藏 Electron 窗口、关闭动画的状态下捕获，正式安装包无需 Playwright。

`pnpm skins:check` 检查客户端操作、两种窗口尺寸与截图；`pnpm skins:export` 生成三套内置包及图集；`pnpm test tests/skins.test.ts` 检查协议及包往返；`pnpm package:skins` 输出新 Windows 客户端。离线展示页 `ui-kit.html` 可切换三套皮肤并查看原状态矩阵。

本轮不提供皮肤市场、在线更新、绘图编辑器或完整 Godot Theme 转换。拆分的 PNG、SVG 与九宫格索引可以作为游戏素材使用，使用时保留各资源授权。
