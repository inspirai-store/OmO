# 素材工坊格式支持与限制

本表区分托管原件、预览和编辑能力。成功归档不会被描述为完整还原。0.1.0 以图片、GLB/glTF 和标准 PBR 为主要路径；复杂工程仍保留原件，详情显示解析失败或能力说明。

| 格式                        | 当前处理                                          | 验证与边界                                                                                  |
| --------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| PNG、JPEG、WebP、BMP、GIF   | 图片查看、元数据、缩略图，GIF 播放                | PNG 与大量真实示例已实际使用；其他格式的所有编码变种尚未遍历                                |
| SVG                         | Sharp 栅格化，不执行脚本                          | 脚本、foreignObject、DOCTYPE 及外部 URL 拒绝；原 SVG 不通过预览协议返回                     |
| TIFF                        | 图片、元数据、多页切换                            | 两页非压缩 RGB TIFF 已自动验证；最多展示 1000 个页面选择项                                  |
| PSD                         | 读取已有合成图                                    | 已验证 8 位 RGB 合成图；CMYK、16/32 位、PSB 与图层效果重算不支持                            |
| KRA                         | 读取 ZIP 内 `mergedimage.png`                     | 自动验证；不执行工程脚本，不重算图层                                                        |
| TGA                         | 独立解码                                          | 常见未压缩与 RLE 真彩色、灰度；未压缩真彩色已自动验证，不承诺索引色全覆盖                   |
| HDR、EXR                    | Three.js 环境与材质球预览                         | HDRI 实际下载；复杂多通道 EXR 依赖加载器能力                                                |
| KTX2                        | Three.js 本地 Basis 转码后查看                    | 面向支持的 Basis Universal 类型；压缩类型兼容矩阵待扩大                                     |
| DDS                         | Three.js DDSLoader 材质球预览                     | 面向加载器支持的类型；不承诺全部 DirectX 压缩与数组纹理                                     |
| GLB、glTF 2.0               | 完整依赖预览、动画、UV、标准 PBR 变体、Godot 导出 | 带外部缓冲和贴图的真实木箱、动画 GLB 与合成模型均已验证                                     |
| Draco、Meshopt、Basis glTF  | 随客户端分发解码器                                | 接入已实现，专项压缩样本矩阵尚未完成                                                        |
| OBJ + MTL                   | 静态模型、贴图、几何信息，生成 GLB 副本           | 保留原件与相对依赖；多种 MTL 方言和命名选项需逐例验证                                       |
| FBX                         | 尽力预览、动画和基础材质，生成 GLB 副本           | Kenney 角色及分离动画已实际验证；版本、坐标与复杂材质可能存在差异                           |
| BLEND                       | 归档；配置 Blender 后转换 GLB                     | 固定转换脚本、禁用自动脚本执行、120 秒超时；本机未安装 Blender，因此实际 Blender 转换待验收 |
| PSB、MAX、MA、MB 及其他工程 | 归档、属性、文件管理器入口                        | 不承诺内部完整预览                                                                          |
| Godot `.tscn`、`.tres`      | 归档、依赖组织                                    | 不在工坊中运行 Godot 场景；交付工程由 Godot 加载                                            |

## 预览和导入容量

普通图像解析限制为 256 MB、1 亿像素；PSD 还限制为 8 位 RGB。glTF/GLB 自动元数据解析超过 256 MB 时提示大模型，查看器仍提供用户主动加载入口。专有解析失败不会删除原件。

导入 ZIP 限制为 20 GB 展开容量、10 万文件，拒绝加密、符号链接、路径穿越和大小写冲突。一个本地目录可超过 ZIP 限额，后台进度与取消保持可用；十万文件目录已实际导入。

非浏览器原生格式生成最大边长 4096 的详细 PNG，缩略图最大 512。RGBA 通道查看最大边长 4096；材质工作台通道重排预览最大 2K，导出通道合并最大 8K。这些都是派生预览限制，原件保持完整。

## 材质导出支持范围

标准金属度—粗糙度 PBR 支持基础色、自发光、法线、粗糙度、金属度、AO、颜色系数、透明裁切/混合、双面、UV0/UV1、过滤和平铺变换。工作台将复杂 glTF 材质扩展和 MeshPhysicalMaterial 标为只读，避免丢失着色语义。

修改粗糙度或金属度的其中一项时，保留原 ORM 的另一项。DirectX 法线必须明确绑定，导出生成绿色通道翻转的派生图，未绑定法线时不猜测源约定。独立 `.tres` 材质使用 UV0，暂不支持 UV1 与旋转；模型变体用 glTF 的纹理变换。

FBX/OBJ 原文件可以导出，材质编辑交付需先生成 glTF/GLB 副本。未知实际单位不自动缩放原件；自动居中只调整相机。最终尺寸和效果应在目标工程确认。

## 尚待完成的完整验收

当前 Windows 约 59.9 GiB 内存机器已测十万文件导入、25 万三角形动画模型的 rAF 调度率、空闲 CPU，以及真实 2K 木箱连续打开和关闭 100 次的内存曲线。具体方法和数值见验收记录，不将这些结果替代 16 GB 基准机测试。

macOS/Linux 的安装与 GPU 桌面验证、严格冷启动、GPU 帧耗时与更长时间的内存稳定性、GPU 上下文丢失实机注入、磁盘耗尽实机注入，以及更多 PSD/FBX/压缩 glTF 编码组合尚未全部验收。

库迁移通过完整备份恢复到新目录实现。当前不提供自动搬迁向导、逐文件缺失依赖定位向导、Godot 使用统计或编辑器插件、完整撤销历史、音视频专用预览、本地语义搜索、团队/NAS/云同步、自动更新和签名发布。

这些项目保留在后续验收和扩展范围中。当前可用功能与已验证结果见用户说明和验收记录。
