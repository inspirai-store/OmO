# 右键菜单与快捷流程

素材、空白区域、项目、收藏集、图片、模型、材质、任务、免费素材和设置均提供右键菜单。「更多操作」调用同一套命令。支持方向键、Enter、Esc、Shift+F10；菜单最多两层，关闭后恢复焦点和滚动位置。

## 选择与整理

右键未选中的卡片只选择该卡片；右键已选卡片保留多选，空白处右键不改变选择。操作对象在菜单打开时固定，缩略图更新不会更换目标或刷新整个列表。

「视图更多操作 → 全选当前筛选结果」覆盖全部分页，一次最多十万个素材。反选也使用全部筛选结果；「查看所选清单」每页一百项。

「整理…」集中修改展示标题、分类、标签、项目和收藏集。标题支持前后缀、普通文字替换与编号，提交前展示数量和标题样例。标签默认追加，可切换替换；未设置的字段保持原值。计划先完整校验，再通过一个事务应用。原始文件名及模型依赖路径保留。

「关联」提供项目和普通收藏集的加入、移出操作；智能收藏集通过规则管理。项目／收藏集右键可编辑和导出，删除只移除组织信息。

## 预览与材质

图片右键提供背景、RGBA、像素显示、网格、图集、帧序列、九宫格、状态对照及参数保存。选择 2–12 张图片，在「素材工具 → 控件状态分组…」填写状态名称，保存后打开对照。两个可预览素材可并排查看。

三维右键拖动超过 6 个 CSS 像素仍然平移，短按右键打开菜单。菜单包含相机、显示模式、网格与 UV、HDRI、动画、截图及格式允许的 GLB 转换。FBX／OBJ 使用已解析预览，BLEND 需要配置 Blender；副本可关联当前项目。

「匹配贴图到模型…」接受 PBR 套组或图片，选择 GLB／glTF、材质槽、UV 与通道。唯一的命名匹配会预填，歧义由用户确认。缺少 UV、材质只读时显示原因；确认后进入已绑定贴图的工作台。

材质菜单提供新建、复制、重命名、对照、导出和删除。贴图槽右键可更换、查看、清除绑定。草稿使用「保存并导出…」；「导出此变体」使用已保存记录。「应用到项目…」固定模型版本与变体，被项目引用的变体不能删除。

## 辅助图与缩略图

自动生成的缩略图是缓存，不是素材。包内图片可在「整理 → 图片用途」手动标记为辅助预览图；不按文件名猜测。

辅助图默认从普通浏览、搜索、分类及项目计数中排除，数量单列。通过「显示辅助预览图」或「所有文件」查看，再次整理可恢复为普通素材。原件、关联和依赖保留。

Godot 不单独导出辅助图，实际依赖仍完整交付；通用资源包保留所选素材同版本包内的辅助图和标记。标准 ZIP 再导入、备份恢复也保留标记。

「重建所选缩略图」进入后台队列，成功只替换对应卡片的缓存 URL，失败保留旧图，不新增素材或引起整页闪动。

## 导出与数据保护

绑定 Godot 工程后，快捷导出先检查依赖、变体和实际文件冲突，通过后创建任务，重启后仍可使用。「导出整个项目」使用固定版本与选定变体；没有绑定或检查失败时打开导出面板。

任务菜单随状态提供暂停、继续、取消、重试、详情、输出和错误复制。Blender 转换不支持暂停，可以取消。免费素材仍先查看规格、依赖与许可，再下载。

设置菜单提供库目录、备份、恢复到新目录，以及缓存占用、清理和重建。回收站提供恢复与需确认的永久清理，继续执行项目和变体引用保护。

Windows 已进行实际 Electron 流程验证；macOS／Linux 的菜单、组合键和安装包仍需对应平台验证。
