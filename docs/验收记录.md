## 2026-10-05：尺寸输入误关修复

复现了在尺寸输入框内按下鼠标、拖到弹窗外松开时，浏览器将 click 重新定位为 dialog，旧背景点击逻辑因此误关弹窗的问题。Dialog 现在同时检查鼠标按下的起点；图像加工编辑器关闭背景点击退出，仍支持关闭按钮和 Escape。数字输入使用独立草稿，清空期间不将有效参数改为 0，逐字输入 64×64 后可正常执行。

新增 Electron 操作回归覆盖点击、Ctrl+A 清空、逐字输入、Tab、上下键、Enter、拖到背景松开、背景点击、实际 64×64 输出，以及普通项目弹窗仍可正常通过背景点击关闭。修复程序位于 `release/processing-input-fix/win-unpacked/素材工坊.exe`，启动脚本优先使用此版本。证据见 [修复验证](processing-input-fix-validation.json)。

## 已完成验证

已修复 `bridge_center_wood.fbx` 预览的 `Cannot read properties of undefined (reading 'a')`。真实文件的 UV 数组结束行缩进不一致，Three.js 文本解析器漏读后续 UV 索引；材质索引数组的末尾逗号还会使索引保留为字符串，造成错误的材质分组。现在仅在预览内存副本中按括号结构规整文本缩进及数组末尾分隔符，托管原件保持不变，二进制 FBX 原样传给加载器。同包 329 个 FBX 均通过解析、有限数值属性与完整材质分组检查。客户端验证覆盖侧栏和展开预览、52 个三角形、UV、三组材质、缩略图、GLB 转换与再次打开，以及真实二进制角色的独立骨骼动画播放。旧解析器失败的 FBX 缩略图在升级后自动重试一次，成功只更新对应卡片；再次失败不会循环重试。证据见 `fbx-parser-validation.json`、`fbx-validation.json`、`tests/fbx.test.ts`、`tests/e2e/fbx.spec.ts` 和 `screenshots/fbx-bridge-fixed.png`。

## 已测性能

实体分类与智能聚合已在 22 组真实来源、13,059 条素材记录的示例库验证：11 类实体均有实际内容，实体模式覆盖 13,059 条普通素材，整包模式包含 23 个素材版本。首次聚合约 476 ms，缓存查询约 104 ms，包含本地 IPC 往返，不作为其他机器性能保证。共享依赖不合并主体，显式状态关系、手动组、跨页全选、版本隔离、辅助图排除、标准包往返和同包交付均有核心测试。真实射击武器组使用独立的 Godot 4.7.2、4.6.3 新工程导入，并实例化 GLB 成功；聚合交付默认优先对应的 GLB/glTF，避免重复格式触发上游 FBX 贴图路径问题。证据见 `aggregation-validation.json`、`tests/aggregation.test.ts` 与 `tests/e2e/aggregation.spec.ts`。
