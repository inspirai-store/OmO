# 客户端视觉接入

P5S 漫画式风格已接入真实 Electron 客户端：导航、素材库、智能聚合、属性详情、工作台、免费素材、任务、设置、材质工作台和业务弹窗。

## 启动

关闭原客户端后，运行项目根目录的 `启动示例工坊.cmd`。启动器使用 `release/p5s-client/win-unpacked/素材工坊.exe`，沿用 `.data/library`。旧版可执行目录保留，正在运行的旧窗口需重启才能载入新界面。

开发：`pnpm dev`。打包新版：`pnpm package:client`。检查真实客户端：`pnpm client:check`。业务验收：`pnpm test:e2e`。组件库验收：`pnpm ui:test`。

## 复用方式

- `src/renderer/src/ui-kit` 提供统一 Theme、按钮、导航、页签、分段选择、统计卡、进度、加载、空状态、通知、原生弹窗和入场/退出机制。
- `client-ui.tsx` 将现有原生按钮属性、ref、事件及表单提交语义接入组件库。预览卡片和贴图选择区域保留固有尺寸。
- `client-theme.css` 在 `.client-theme` 范围桥接原有业务样式；红色为主，免费素材用青色，材质工作台用紫色。装饰层不接收点击，标题文字保持水平。
- App 的页面入场复用 Reveal。右键菜单使用 Presence，退出时立即停止交互。菜单在原生弹窗内打开时挂载到该弹窗，保留键盘操作和触发器焦点恢复。
- 公共 Modal 复用原生 Dialog，Esc、关闭按钮和外侧点击均支持退场与焦点恢复。关闭后等待原生模态层退场结束，再操作背景页面。`Dialog` 新增可选 `className`、`closeLabel`、`onExitComplete`；原有调用保持兼容。
- 系统减少动画设置自动取消位移、回弹、旋转及循环动画，仅保留短透明度变化。模型、贴图和图片预览保留实际内容与渲染参数，主题不施加滤镜。
- 缩略图入口独立于客户端 Theme，继续输出原始缩略图。

## 验证与截图

`validation.json` 记录真实 IPC 导入、中文长文件名、键盘页签、菜单/弹窗焦点恢复、六页面两种窗口尺寸、减少动画及缩略图入口检查。截图使用 CSS 像素输出，覆盖 1050×700 和 1510×950。Playwright 业务验收覆盖导入、批量整理、聚合、虚拟滚动、OBJ/FBX 预览与转换、材质编辑、导出和重启。

测试使用独立临时素材库和 Electron 用户目录，不修改现有素材库。
